ComicInfo Metadata Policy

Choose the library-wide default for handling ComicInfo.xml in incoming CBZ files, scheduled maintenance, and QC repairs.

Leave alone keeps existing ComicInfo.xml files unchanged. It is useful when another application manages chapter metadata. Update synchronizes Series / SeriesSort and parsed chapter identity (Number, Title, Volume, and Special format), while preserving other metadata; it does not create a missing XML file. Remove deletes ComicInfo.xml from each CBZ that contains it. Replace writes the saved global or manga template, with chapter placeholders resolved for each file. Upgrade fills missing template fields without replacing existing values. Replace and Upgrade require a saved template. Saving this policy sets the default for future incoming files, scheduled metadata maintenance, and QC repairs; it does not immediately rewrite existing chapters. Use the manga-level Apply action below to run the currently selected policy on one manga. Library Manager renames continue to refresh chapter identity metadata as part of the rename operation.

Chapter placeholders

Place these inside an element's text. PanelKeeper resolves them separately for each CBZ when previewing or applying Replace / Upgrade.

{{Series}}{{ChapterNumber}}{{ChapterTitle}}{{ChapterLabel}}{{Volume}}{{Format}}{{IsSpecial}}{{SpecialNumber}}{{SpecialTitle}}{{LetterSuffix}}{{FileName}}

Example: <Number>{{ChapterNumber}}</Number>, <Title>{{ChapterTitle}}</Title>, <Format>{{Format}}</Format>. ChapterTitle is blank if the filename has no parsed title. Format is Special for a parsed Special and blank otherwise. Unknown / unavailable values become empty text, not unresolved placeholders.
